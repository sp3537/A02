# A02 GitHub Tutorial

## Introduction
In this Tutorial we will learn how to set up Webstorm, GitHub and Git. We will also learn how to create a repository, open it in WebStorm and understand some common Git and GitHub terms.

## Part 1:  Directions on Using WebStorm

### Step 1: Download and Install WebStorm
 1. Go to https://www.jetbrains.com/webstorm/
 2. Download and Install WebStorm for your computer

### Step 2: Make GitHub Account (Skip if you already have one)
1. Go to https://github.com
2. Make an Account

### Step 3: Download and Install Git (Skip if you already have installed)
1. Go to https://git-scm.com/downloads
2. Download and Install for your computer
3. To check the installation open terminal or command prompt
4. Type git --version

### Step 4: Setting up repository with WebStorm
1. Go to https://github.com
2. Find a plus icon on top that will get a drop down menu
3. Select New repository
4. Fill in the info like the name of the repo or optional add readme file or description
5. Select create repository to complete creating repository.
6. Select Green Code button on right
7. Select HTTPS and copy the URL
8. Turn on WebStorm
9. Find Clone Repository
10. Paste The URL in URL slot
11. Select clone
12. Select Trust Project to complete setting up

## Part 2: Glossary
- Branch: A different version of a project where changes can be made without changing the main project.
- Clone: Making a copy of a GitHub repository on a local device.
- Commit: Saving a change in Git with a message explaining what was changed.
- Fetch: Checking for new changes from a remote repository without automatically adding them.
- GIT:  A version control system used to track changes in files.
- GitHub: A website used to store Git repositories.
- Merge: Combining changes from one branch into another branch.
- Merge Conflict: A problem that happens when Git cannot automatically combine changes.
- Push: Sending committed changes from your computer to a GitHub repository.
- Pull: Downloading changes from GitHub to a local computer.
- Remote: A version of a repository that is stored online.
- Repository: A project folder that contains files and tracks changes.
